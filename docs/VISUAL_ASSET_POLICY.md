# LinguaLab Visual Asset Policy

This policy applies to every visual asset added to LinguaLab, including images, icons, illustrations, diagrams, and decorative graphics.

## Approved sources

Prefer visual assets created specifically for LinguaLab:

1. AI-generated visuals created for LinguaLab.
2. CSS or SVG visuals created inside the LinguaLab codebase.
3. Charts generated from LinguaLab's own data.

## External assets

Do not add an external image, icon, illustration, or graphic unless its license has been explicitly verified for the intended use. Record the source, license, and any attribution requirement before including it in the repository.

Stock images and third-party icon packs must not be added by default. If an external asset is genuinely necessary, its verified license and attribution requirements must be documented in the same change.

When an asset's licensing status is unclear, do not use it.

## Existing functionality

Applying this policy must not change current LinguaLab functionality. Prefer a code-native or LinguaLab-generated visual when a compliant replacement is needed.
