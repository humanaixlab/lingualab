# LinguaLab synthetic demonstration dataset

The files named `arabic_reviews_demo` contain **fully synthetic Arabic records generated specifically for LinguaLab demonstrations**.

- They do not contain real user data.
- They were not scraped, copied from reviews, or derived from an external dataset.
- The text records were created specifically for LinguaLab.
- The CSV and XLSX files contain the same 30 records using the schema `text,label`.
- The labels are balanced across `إيجابي`, `محايد`, and `سلبي`.
